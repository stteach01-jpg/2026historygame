操作指引

教師建立基地

  1. 確認基地代碼，例如 HISGAME；HISGAME01 使用 5x5 棋盤與戰後世界的局勢題庫。
  2. 按「教師建立基地」。
  3. 請學生用同一個基地代碼加入。
  4. 所有玩家出現在清單後，按「開始遊戲」。

學生登入

  1. 輸入教師指定的基地代碼。
  2. 按「學生加入」。
  3. 輸入玩家代號，例如 902-02。
  4. 按「加入」，等待輪到自己擲骰。

遊戲流程

  1. 輪到的玩家擲骰。
  2. 題目會自動跳出。
  3. 答對留在新位置，答錯退回原位置。
  4. 掉入陷阱退回前一次位置；取得金牌免回答題目。
