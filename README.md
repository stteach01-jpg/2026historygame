# 時間線指揮官

一個以歷史事件排序為核心的互動遊戲原型。玩家需要判斷事件發生順序，累積連勝並挑戰更高分。

## 啟動

直接用瀏覽器開啟 `index.html` 即可遊玩。

## 目前版本

- 零依賴，不需要 npm install
- 內建中國史、世界史、台灣史事件題庫
- 分數、連勝、最佳連勝紀錄
- 支援桌面與手機版面

## 工作模式

- 專案規則看 `AGENTS.md`
- 進度與下一步記在 Obsidian：`2026historygame/專案工作流程.md`
- 開始工作時可說「開工」
- 結束工作時可說「收工」

## 專案結構

- `index.html`: 遊戲畫面結構
- `src/main.js`: 主要遊戲流程
- `src/data/events.js`: 歷史事件題庫
- `src/styles.css`: 介面樣式
