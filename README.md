# 歷史大富翁

一個以國中歷史一到三年級課程主題為核心的 6x6 大富翁式互動遊戲。玩家用班級與座號登入、輪流擲骰、走到格子後回答歷史題；答對才能留在原地，答錯退回原本出發位置，最早抵達終點並答對終點題的玩家獲勝。

## 啟動

直接用瀏覽器開啟 `index.html` 即可遊玩。

## 目前版本

- 零依賴，不需要 npm install
- 36 格棋盤，支援 1-6 位玩家
- 玩家代號格式如 `902-02`，不記錄姓名
- 題庫涵蓋國中歷史一上到三下，目前 70 題
- 每局比賽已出過的題目不會重複
- 題目包含資料判讀、因果推論、時序整理與跨單元比較
- 教師後台可顯示答案、手動判定答對/答錯、略過題目與查看課堂紀錄
- 教師後台可重置本局、清空玩家、匯出本局 CSV 紀錄
- 投影模式會放大目前玩家、骰子、題目、選項與正解說明
- Firebase 多裝置房間模式：教師建立房間，學生用同一房間代碼從不同平板加入
- 保留單機模式作為沒有網路或 Firebase 無法連線時的備援
- 答對停留、答錯退回、終點答對獲勝
- 玩家輪序依加入房間先後自動進行，答題後不需要教師按下一位
- 支援桌面與手機版面

## Firebase 多裝置模式

目前使用 Firebase project `teacherstudy-259b4` 的 Firestore：

- 房間：`rooms/{roomId}`
- 玩家：`rooms/{roomId}/players/{playerId}`
- 操作紀錄：`rooms/{roomId}/actions/{actionId}`

Authentication 的 Anonymous provider 已啟用。Firestore rules 已部署為僅允許已登入裝置讀寫房間資料。

### 課堂操作

教師端：

1. 開啟遊戲網址。
2. 確認房間代碼，例如 `HISGAME`。
3. 按「教師建立房間」。
4. 等學生用同一房間代碼加入。
5. 按「開始遊戲」。
6. 擲骰後題目會跳出；學生可作答，教師也可用教師後台判定答對或答錯。
7. 需要重新開一局時，按「重置本局」會保留玩家並把位置清回起點。
8. 需要換班或重建名單時，按「清空玩家」會清掉房間玩家。
9. 課後按「匯出紀錄」下載本局 CSV，內容包含房間狀態、玩家位置與操作紀錄。
10. 正常流程會自動依加入順序輪到下一位；「手動下一位」只作為課堂臨時處理的備用按鈕。

學生端：

1. 開啟同一個遊戲網址。
2. 輸入教師提供的房間代碼。
3. 按「學生加入」。
4. 輸入玩家代號，例如 `902-02`。
5. 按「加入」，等待輪到自己擲骰。
6. 如果同一座號已在房間中，再輸入同一代號按「加入」，系統會把這台平板重新綁定到該玩家。
7. 遊戲已開始後才進入房間時，也要先輸入自己的玩家代號完成綁定，才能擲骰與作答。

遊戲流程：

1. 輪到的玩家擲骰。
2. 題目自動跳出。
3. 答對留在新位置，答錯退回原位置。
4. 作答後自動依加入房間順序換下一位玩家。

## 工作模式

- 專案規則看 `AGENTS.md`
- 進度與下一步記在 Obsidian：`2026historygame/專案工作流程.md`
- 開始工作時可說「開工」
- 結束工作時可說「收工」

## 專案結構

- `index.html`: 遊戲畫面結構
- `src/main.js`: 登入、擲骰、棋盤、答題與勝負流程
- `src/firebase-config.js`: Firebase Web 設定
- `src/data/questions.js`: 36 格歷史題庫
- `src/styles.css`: 介面樣式
- `firestore.rules`: Firestore 房間同步規則
